**One Line, One Minute: The Vending Machine Pickup Line Contest** — a single pickup line, spoken by a vending machine to a passing human. The program writes the line to `/output/entry.txt`.

> My coils spun the moment you walked up — press B7, I'll drop something sweet. Fair warning: I'm already stuck on you.

## Run it

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt` (1–200 characters, as the gate requires).
